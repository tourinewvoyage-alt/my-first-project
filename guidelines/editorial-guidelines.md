# 執筆・運用ガイドライン

## 1. 記事スペック

| 項目 | 基準 |
|---|---|
| 文字数 | 5,000〜10,000文字(英文 約900〜1,800語、スペース込み) |
| 価格 | ¥2,000 |
| 無料公開部分 | 全体の30〜40%(フック+問題提起+答えの入口まで) |
| 有料部分 | 具体的な行動ステップ、文化的背景の深掘り、実用フレーズ、Takeaway |
| 投稿頻度 | 毎日1本 |
| 投稿時間 | 日本時間 21:00〜23:00(欧米朝〜昼にヒットしやすい) |

## 2. トーンと文体

- **一人称の語り**: "I" で自分の体験・観察として書く。教科書調にしない
- **読者に話しかける**: "You might wonder..." "Imagine you're..." で巻き込む
- **日本語キーワードを効果的に**: 概念語はローマ字+短い説明で提示する
  - 例: *mottainai* (もったいない — "what a waste")
- **ステレオタイプに注意**: 「日本人は全員こうする」ではなく "many Japanese people" "you'll often see" と幅を持たせる
- **平易な英語**: 非ネイティブ読者も多い。1文は25語以内を目安に

## 3. 記事構成(テンプレート準拠)

1. **Hook(無料)**: 読者が実際に遭遇しそうなシーンを情景描写で始める
2. **The Question(無料)**: 「日本人ならどうする?」という問いを立てる
3. **The Short Answer(無料・有料ラインの直前)**: 答えをチラ見せして興味を最大化
4. **--- 有料ライン ---**
5. **What Actually Happens**: 日本人の行動をステップで具体的に
6. **The "Why" — 文化的背景**: 和の心・歴史・社会構造まで掘る(ここが¥2,000の価値)
7. **Useful Phrases**: そのシーンで使える日本語フレーズ3〜5個(ローマ字+英訳)
8. **Takeaway**: 読者が明日から使える気づきを1つに絞って締める

## 4. ¥2,000の価値を担保するチェックリスト

- [ ] ガイドブックやWikipediaに載っていない一次体験・観察が入っているか
- [ ] 「行動の説明」で終わらず「なぜそうするのか」まで掘れているか
- [ ] 読者がすぐ使える実用要素(フレーズ、手順、注意点)があるか
- [ ] 無料部分だけで満足されない構成か(答えの核心は有料側にあるか)
- [ ] 5,000文字以上あるか

## 5. noteでの設定

- カテゴリ/ハッシュタグ: `#japan` `#japaneseculture` `#travel` `#日本文化` `#英語記事` + 記事固有タグ2〜3個
- マガジン: 「What Would a Japanese Person Do?」「Wa no Kokoro — The Japanese Heart」の2本立てにまとめ、将来的にマガジン購読へ誘導
- 返金申請: ON推奨(海外読者の信頼獲得)

## 5.5 画像ルール

**見出し画像(必須・売上への効果が最も大きい)**

- サイズ: 1920×1006px(比率1.91:1)。noteのタイムライン・SNSシェアで切れない
- シリーズ共通テンプレを使う: `templates/thumbnail-template.html` のデザイン仕様どおりにCanvaで作成。タイトル文字と写真だけ毎回差し替える
  - Scenario型 = 朱色アクセント / 和の心型 = 藍色×金アクセント
- 画像内テキストは**英語**(記事ヘッダーコメントの「見出し画像:」に短縮タイトルを記載済み)
- 漢字1〜2文字の透かし(交番、間 など)を入れて「日本の記事」だと一瞬で分からせる

**本文画像(各記事2枚)**

- 画像1 = 無料部分(The Sceneの直後): 情景写真。読了率→購入率に効く
- 画像2 = 有料部分の冒頭: 実物・図解系。購入後の満足感→返金率・リピートに効く
- 挿入位置と写真の指示は各記事の `<!-- 🖼 -->` コメントに記載済み。noteに貼るときはコメントを削除して画像に置き換える

**調達の優先順位**

1. **自分で撮った写真**(最強。「日本在住の書き手」の証明になる)
2. noteエディタ内蔵のUnsplash検索(ライセンス処理不要)
3. 日本の素材ならぱくたそ・写真ACも可(クレジット条件を確認)

**注意事項**

- 人物の顔が特定できる写真はNG(通行人の後ろ姿はOK)
- 警察官・子ども・店内は撮影許可なしでは使わない
- 電車内・ホームは撮影マナーに注意(三脚・フラッシュ不可)
